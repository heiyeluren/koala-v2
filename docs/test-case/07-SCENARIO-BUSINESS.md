#### TC-BZ-009-Post_Combined_Limits 🔴

  5. 第 11 次尝试（被每日限制拦截）

## 4. 系统安全场景

### 4.1 登录保护

#### TC-BZ-014-Login_Fail_Protect 🔴
```
描述: 登录失败保护
场景: 连续失败 5 次需要滑块验证
测试步骤:
  1. 模拟登录失败 5 次
  2. 第 6 次尝试
预期结果:
  - 返回 auth_type=1（滑块验证）
```

#### TC-BZ-015-Login_Fail_Reset 🔴
```
描述: 登录失败计数重置
场景: 10 分钟后失败计数重置
测试步骤:
  1. 登录失败 3 次
  2. 等待 10 分钟
  3. 再次登录失败
预期结果:
  - 计数从 1 开始
```

#### TC-BZ-016-Login_Success_After_Fail 🔴
```
描述: 失败后成功登录
场景: 失败多次后成功登录是否重置计数
测试步骤:
  1. 登录失败 3 次
  2. 成功登录
  3. 再次登录失败 3 次
预期结果:
  - 根据业务逻辑决定是否重置
```

#### TC-BZ-020-Crawler_BaseControl 🔴
```
描述: 爬虫 Base 控制
场景: 同 IP 超过 20 次后，每 10 秒限 1 次
测试步骤:
  1. 同一 IP 发送 20 次请求（正常）
  2. 第 21 次请求
  3. 等待 5 秒，第 22 次请求
  4. 等待 10 秒，第 23 次请求
预期结果:
  - 前 20 次正常
  - 第 21 次正常（刚达到 base）
  - 第 22 次被拒绝（5秒内）
  - 第 23 次允许（间隔超过 10 秒）
```
