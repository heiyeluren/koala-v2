# 01 - 产品概述

## 1.1 系统定位

Koala V2 是一个**高性能频率控制与反作弊系统**，为 GIL 教育平台提供统一的请求频率限制、行为控制和反欺诈能力。

### 核心价值

| 价值 | 说明 |
|------|------|
| **集中管理** | 将分散在各业务代码中的频控逻辑集中到配置文件 |
| **配置驱动** | 通过配置文件管理所有规则，无需修改代码 |
| **高性能** | 单机 10W+ QPS，P99 延迟 < 10ms |
| **高可用** | 支持 Redis 故障自动降级到本地存储 |
| **热更新** | 规则配置变更无需重启服务 |

### 解决的问题

1. **频率控制分散**: 各业务代码各自实现限流，难以统一管理
2. **规则修改困难**: 修改限流规则需要改代码、发版本
3. **缺乏灵活性**: 无法快速响应运营需求调整策略
4. **监控困难**: 缺乏统一的频控数据统计和监控

## 1.2 核心功能

### 1.2.1 四种限流算法

| 算法 | 用途 | 示例 |
|------|------|------|
| **Direct** | 黑白名单直接决策 | VIP 用户直接放行 |
| **Count** | 时间窗口计数限制 | 每天最多发帖 10 次 |
| **Base** | 阈值触发二级限制 | 超过 10 次后每 5 秒限 1 次 |
| **Leak** | 漏桶平滑限流 | 60 秒内平滑限制 100 次 |

### 1.2.2 访问控制

- IP 白名单 / 黑名单
- 用户 ID 白名单 / 黑名单
- 字典文件动态加载

### 1.2.3 规则匹配

- 精确匹配: `act = "post"`
- 取反匹配: `act = "!post"`
- 多值匹配: `uid = "1,2,3"`
- 范围匹配: `uid = "1-100"`, `uid = ">1000"`
- 通配匹配: `ip = "192.168.*"`
- 字典引用: `uid = "@whitelist"`

### 1.2.4 运维能力

- Prometheus 指标暴露
- 健康检查接口
- 配置热重载
- 存储降级保护

## 1.3 技术选型

### 1.3.1 核心技术栈

| 组件 | 选型 | 说明 |
|------|------|------|
| 语言 | Go 1.21+ | 高性能、并发友好 |
| HTTP 框架 | Gin | 高性能、生态成熟 |
| 配置格式 | TOML | 可读性好、类型安全 |
| 日志 | Zap | 高性能结构化日志 |
| 监控 | Prometheus | 云原生标准 |
| 主存储 | Redis | 高性能、支持集群 |
| 本地缓存 | Ristretto | 高性能 LRU 缓存 |

### 1.3.2 第三方依赖（本地化）

所有关键依赖代码拉取到本地 `third_party/` 目录，避免远程版本变更风险：

| 依赖 | 原始仓库 | 本地路径 |
|------|---------|---------|
| Ristretto | dgraph-io/ristretto | third_party/ristretto |
| Zap | uber-go/zap | third_party/zap |
| Redis Client | go-redis/redis | third_party/redis |

## 1.5 部署模式

### 1.5.1 单机模式

```
Client → Koala → Redis (可选)
              ↘ Local Cache
```

适用场景: 开发测试、小规模部署

### 1.5.2 集群模式

```
              ┌→ Koala-1 ─┐
Client → LB ──┼→ Koala-2 ─┼→ Redis Cluster
              └→ Koala-N ─┘
```

适用场景: 生产环境、高可用需求

## 1.6 应用场景

### 学生端

| 场景 | 规则示例 |
|------|---------|
| AI 问答限制 | 普通用户每天 50 次，VIP 200 次 |
| 评论限制 | 每天最多评论 10 次 |
| 发帖限制 | 每分钟最多 3 次 |

| 场景 | 规则示例 |
|------|---------|
| 资源上传 | 每天最多 50 个 |
| 作业发布 | 每天最多 5 次 |
| 试卷编辑 | 每 5 分钟最多 3 次 |

| 场景 | 规则示例 |
|------|---------|
| 登录保护 | 连续失败 5 次锁定 |
